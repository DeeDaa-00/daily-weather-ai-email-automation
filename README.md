# Daily Weather AI Email Automation

An automated workflow that sends a clear daily weather report by email.

## Project Overview

This project collects daily weather information for Bahrain, creates an easy-to-read weather summary and recommendation, then sends it by email automatically.

## How It Works

1. A daily schedule starts the workflow.
2. Current weather information is collected.
3. AI creates a readable weather report.
4. The report is delivered by email.

## Key Features

- Daily automated weather updates
- Current temperature and weather conditions
- Wind and feels-like temperature
- Practical daily recommendation
- Clean email formatting

## Project Status

The workflow has been set up, tested, and published. It is ready to run on its daily schedule.
